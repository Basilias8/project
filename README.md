# FOOTYSUPER⁵: LEGENDARY EDITION

Реалистичный футбольный менеджер с глубокой системой развития карьеры

## О проекте

FOOTYSUPER⁵: LEGENDARY EDITION - это захватывающий футбольный менеджер, где вы создаёте собственного игрока и ведёте его к мировой славе. Начните карьеру в скромном клубе и пройдите путь до звёзд мирового футбола!

## Ключевые возможности

- Глубокая система карьеры - от новичка до легенды
- Реалистичные матчи и статистика
- Международные турниры (Лига Чемпионов, Чемпионат Мира)
- Мини-игры для улучшения навыков
- Система аналитики с графиками прогресса
- Трансферная система с реальными клубами
- Кастомизация внешности игрока
- Управление стадионом
- Система репутации и достижений

## Игровой процесс

### Начало карьеры
- Создайте игрока с уникальными характеристиками
- Начните в клубе низшей лиги
- Развивайте навыки через тренировки и матчи

### Основные механики
- Тренировки - улучшайте рейтинг игрока
- Матчи - участвуйте в чемпионатах
- Трансферы - переходите в более сильные клубы
- Турниры - выигрывайте международные трофеи
- Аналитика - отслеживайте прогресс

### Система развития
Новичок (60-69) → Перспективный (70-79) → 
Звезда клуба (80-84) → Звезда лиги (85-89) → 
Мировая звезда (90-94) → Легенда (95+)

## Управление

- Навигация в меню: СТРЕЛКИ ВВЕРХ/ВНИЗ
- Выбор пункта: ENTER
- Назад/Выход: ESC
- В мини-играх: WASD + ЛКМ

## Мини-игры

### 1. Попади по цели
- Цель: Попасть по максимальному количеству целей за 30 секунд
- Управление: Мышь
- Награда: +0.5 к рейтингу при счёте >10

### 2. Дриблинг через конусы
- Цель: Пройти через все конусы за 45 секунд
- Управление: WASD
- Награда: +0.5 к рейтингу при счёте >50

## Решение проблем

### EXE файл не запускается
1. Убедитесь, что у вас Windows 7+
2. Проверьте наличие .NET Framework 4.5+
3. Запустите от имени администратора

### Нет изображений/звуков
- Игра создаст заглушки автоматически
- Основной функционал будет работать

### Сохранения не работают
- Проверьте права на запись в папку игры
- Убедитесь, что папка saves существует
